# 🛍️ SmartBuyHub

**SmartBuyHub** is a full-stack web application for browsing, favoriting, and viewing detailed product information. Built using **React**, **Node.js**, and **MySQL**, it provides user registration, login, personalized profile, product categorization, and more.

---

## 🔧 Setup Instructions

### ✅ Prerequisites

- Node.js (v16 or higher recommended)
- MySQL (v8 or higher)

---

### 🚀 Installation Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/songkehe/SmartBuyHub.git
   cd SmartBuyHub
   Backend setup
